How to View the Image Gallery

The image collection may be viewed in two ways:

View Collection with Insight Browser
The Insight Browser is the easiest way to view the collection. It utilises any typical web browser and requires no plug-in or downloads. This browser is recommended for first-time users.

or

Download Insight Java Client
The Insight Java Client is a fully featured Java application that provides advanced features and additional functionality over the Insight Browser. The Java Client is recommended for researchers and frequent users but must be downloaded.

The Insight Browser and Java client software are products of Luna Imaging, Inc (Opens in a new tab)., Los Angeles.

Insight Browser Online Help - The Insight Online help provides an overview of the major features of the Browser version of Insight, and opens in your default web browser.

Insight Java Client Online Help - The Insight Online help provides an overview of the major features of Insight, and opens in your default web browser. This is the same help page that is available within the Insight software.
